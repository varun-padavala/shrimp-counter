# 🦐 Shrimp Counter

**AI-powered shrimp seed counting, built for real-world aquaculture farms.**

Shrimp Counter is an Android application that helps shrimp seed farms estimate shrimp counts using a smartphone camera and on-device AI. It is designed for fast, practical counting—even in locations with limited or no internet connectivity.

🌐 **Website:** [shrimp-counter-nine.vercel.app](https://shrimp-counter-nine.vercel.app/)

📥 **Download:** [Get the latest Android APK from GitHub Releases](https://github.com/varun-padavala/shrimp-counter/releases)

---

## ✨ Features

- 📷 **Camera-based counting** — Capture shrimp seed samples directly from your phone.
- 🤖 **On-device AI** — Perform counting on the device without requiring an internet connection for the core counting functionality.
- 🧠 **Adaptive model selection** — Supports different shrimp seed sizes with appropriate AI models.
- 🎯 **Tray positioning guide** — Helps position the sample for easier camera framing.
- 📸 **Camera controls** — Includes zoom and capture controls.
- 🕘 **Recents** — Access recent unsaved counts, retained for up to 3 days.
- 📋 **Records** — Save and review counting results.
- 📊 **Counting statistics** — Track counting activity.
- 🧮 **Built-in calculator** — Assist with counting-related calculations.
- 🔄 **Application updates** — Support for app updates.
- 🧠 **AI model updates** — Support for updating AI models.
- 🌙 **Dark interface** — Designed for comfortable use in the field.

## 🔄 How It Works

```text
Position the tray
       ↓
Adjust the camera
       ↓
Capture the sample
       ↓
Run AI counting
       ↓
Review the result
       ↓
Save or continue
```

The core counting functionality works offline, making Shrimp Counter useful in farm environments where internet access may be unreliable.

## 📥 Installation

1. Open the [Shrimp Counter Releases page](https://github.com/varun-padavala/shrimp-counter/releases).
2. Download the latest APK compatible with your Android device.
3. For most modern Android phones, choose the **ARM64** build when available.
4. Open the downloaded APK and follow Android's installation prompts. You may need to allow installation from your browser or file manager.

> **Note:** Counting speed and accuracy may vary depending on device hardware, sample quality, lighting, and the AI model being used.
